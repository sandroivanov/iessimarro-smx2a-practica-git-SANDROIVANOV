#Aula Digital - Projecte Intermodular SMX 

Transfomarcio d'una aula tradicional en una aula digital: mobiliari
especific per a ordinador, armari rack amb switch i router, rosetes
RJ45 a la paret per a una xarxa d'area local, eixida a internet, 
pissara digital i impresora en xarxa

- Rol B - Instal.lacio fisica i xarxa
